# Poker Analysis Website — Requirements Document

## 1. Overview

A static dark-themed website hosted on GitHub Pages (`https://fli-rpx.github.io/poker_analysis/`) that serves as Frank's daily poker strategy hub. The site aggregates daily poker tips (delivered by the poker-companion cron job), displays poker philosophy, and links to hand history analysis results.

## 2. Data Source

The daily poker tips are delivered by a Hermes cron job (`poker-companion`) that runs at 09:00 daily. Each tip is ~2-3 paragraphs, conversational, tailored to Frank's game.

**Existing data locations:**
- Poker principles: `/Users/fudongli/.hermes/profiles/hermes4/poker/poker-principles.txt`
- Hand history data: `/Users/fudongli/.hermes/profiles/hermes4/poker/history/` (166+ GG2026*.txt files)
- Review tool: `/Users/fudongli/.hermes/profiles/hermes4/poker/poker-review.py`
- Baseline metrics: JUNK% = 57% (target <20%), junk showdown win rate = 8%, high PP win rate = 65%
- Tip history: tracked in tip-history.md

## 3. Site Structure

### 3.1 Pages

**A. index.html — Daily Strategy (landing page)**
- Shows **today's** daily poker tip in full
- Two navigation links at the top:
  - "Philosophy" → `/philosophy.html`
  - "Hand History Analysis" → `/analysis.html`
- Bottom section: "Past Strategy Tips" — a reverse-chronological list of all previous tips with dates
- Footer: "Generated by Hermes Agent · Poker Companion"

**B. philosophy.html — Poker Principles**
- Full display of Frank's Poker Principles (poker-principles.txt)
- Sections rendered with proper typography:
  - The River (title banner)
  - Why No Desire?
  - The Practice (The Recite)
  - Quantum Analysis
  - Bluffing
  - Squeezing
  - Attack Patterns
  - Signs from God
  - Reminders
- Back link to index.html

**C. analysis.html — Hand History Analysis**
- Shows the latest baseline metrics from `poker-review.py --baseline` output
- Key metrics displayed prominently:
  - JUNK% (big number, red if >20%, green if ≤20%)
  - Junk showdown win rate
  - High PP (TT+) win rate
  - High PP volume %
  - Overall showdown win rate
  - Total hands analyzed
- A table or list showing past analysis results over time (from data/analysis_history.json)
- Back link to index.html

## 4. Visual Design

- **Dark theme** matching Frank's poker aesthetic
- Color palette (from the iPhone app design):
  - Background: #0A0A0A (near-black)
  - Surface: #1A1A1E (cards, containers)
  - Gold accent: #D4AF37 (the river, premium hands)
  - Blue accent: #4A90D9 (quantum connections)
  - Red warning: #E74C3C (danger, JUNK% over target)
  - Green safe: #27AE60 (JUNK% under target)
  - Text primary: #F5F5F0 (warm white)
  - Text dim: #6B6B70 (secondary)
- Typography: Inter or system sans-serif for UI, Georgia or serif for principles/recite
- Gold horizontal rule separator (─── style from the principles file)
- Responsive (mobile-friendly, since Frank may view on phone)
- No JavaScript framework — pure HTML + CSS
- index.html loads tips.json via fetch at page load to render the latest tip and past tips list

## 5. Daily Refresh Script

A Python script `scripts/refresh_daily.py` that:

1. **Reads the latest daily tip** from `/Users/fudongli/.hermes/profiles/hermes4/poker/last_tip_date.txt` and the tip history from the poker-companion skill reference file to find the latest tip title and content (or read from a tips export mechanism)

2. **Appends new tips to `data/tips.json`** — if today's tip isn't already in the JSON, add it

3. **Runs `poker-review.py --baseline`** to get current metrics, appends a snapshot to `data/analysis_history.json`

4. **Commits and pushes** the updated data files to the repo (GitHub Pages auto-deploys)

### Script location: `scripts/refresh_daily.py`
### Cron schedule: Daily at 09:15 (15 min after the poker tip cron, to let it complete first)

## 6. GitHub Pages Setup

- Source: Deploy from `main` branch, root directory
- Custom domain: none (use default `fli-rpx.github.io/poker_analysis/`)
- The repo root serves:
  - `index.html` → landing page
  - `philosophy.html` → principles
  - `analysis.html` → hand history analysis
  - `data/` → JSON data files (loaded by fetch)
  - `scripts/` → refresh script (not served, just in repo for cron)
  - `style.css` → shared styles
